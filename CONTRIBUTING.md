# Contributing to hactl-companion

This is the Home Assistant add-on that backs [hactl](https://github.com/hemm-ems/hactl).
Same opinionated stance on contributions — please read it before opening anything.

## The deal

**We live in an AI world. If your AI can find a bug, it can fix it.** So if you (or your agent)
found a real problem, the most useful thing you can do is open a **pull request** with the fix.

- **AI-written issues are rejected.** Issues that are clearly generated by an LLM get closed as
  invalid (`ai-generated`). No exceptions, no hard feelings.
- **Human-written issues are always welcome.** If you hit something and can't fix it yourself,
  write it up *in your own words* — short and concrete beats long and polished.
- The bug form asks for exact versions, what you did, and the full logs. That's what lets the
  maintainer's LLM reproduce the problem and fix it. An issue I can't reproduce I can't fix.

## Found a bug?

1. **Can your AI fix it?** Open a PR. See below.
2. **Can't fix it?** Open a [bug report](https://github.com/hemm-ems/hactl-companion/issues/new/choose) —
   written by you, by hand. Include:
   - the add-on version (Settings → Add-ons → hactl companion)
   - your HA version and install type (HA OS / Supervised / Container)
   - exactly what you did
   - what you expected vs. what happened — paste the add-on **logs**

## Have an idea?

Open a [feature request](https://github.com/hemm-ems/hactl-companion/issues/new/choose) —
written by a human. Tell me the problem you're solving, not just the solution.

## Questions / how-to

Not a bug? Use [Discussions](https://github.com/hemm-ems/hactl-companion/discussions).

## Pull requests

**AI-assisted PRs are welcome — that's the whole point.** I care that it's correct, tested, and
reviewable, not who typed it.

Before you open a PR:

- [ ] It's linked to an issue, or the description explains the change and why.
- [ ] `pytest` passes.
- [ ] `make lint` (ruff) is clean.
- [ ] Docs updated if behavior changed.

Working on the code? See [AGENTS.md](AGENTS.md) for the norms.

## Security

Never open a public issue for a vulnerability. Use
[private reporting](https://github.com/hemm-ems/hactl-companion/security/advisories/new).
See [SECURITY.md](SECURITY.md).

## Code of Conduct

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md). Be decent.
